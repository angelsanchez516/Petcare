# Versión archivada — modelo de 52 tablas

Esta carpeta conserva el esquema completo de 52 tablas que incluía
hospitalización, cirugía, laboratorio, compras, inventario con kardex y
permisos granulares.

Se archivó cuando el equipo decidió simplificar el alcance de la primera
entrega a 28 entidades. El esquema vigente está en la carpeta superior.

No se borra por si el proyecto retoma esos módulos más adelante.
